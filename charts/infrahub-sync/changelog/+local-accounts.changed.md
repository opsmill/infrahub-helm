The Sync API authenticates local accounts instead of the bearer tokens of `credentials.bearerTokens`, which the chart no longer reads. Set the password of the `admin` account in `credentials.adminAccountPassword` (required) and, optionally, its API token in `credentials.adminAccountToken`. The chart gives them to the Sync API only, as `INFRAHUB_SYNC_ADMIN_ACCOUNT_PASSWORD` and `INFRAHUB_SYNC_ADMIN_ACCOUNT_TOKEN`. The new `settings.sessionIdleSeconds` sets `INFRAHUB_SYNC_SESSION_IDLE_SECONDS`. This requires an Infrahub Sync release that has local accounts.
