Infrahub Sync {{ include "infrahub-sync.image" . | splitList ":" | last }} is being deployed in the namespace {{ .Release.Namespace }}.

1. Wait for the bootstrap Job to complete:

  kubectl --namespace {{ .Release.Namespace }} wait --for=condition=complete --timeout=15m job -l {{ $bootstrap }}

2. Reach the Sync API from your workstation:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ $api }} {{ .Values.api.service.port }}:{{ .Values.api.service.port }}

  Then, in another terminal:

  export INFRAHUB_SYNC_API_URL=http://127.0.0.1:{{ .Values.api.service.port }}
  export INFRAHUB_SYNC_API_TOKEN='<your API token>'
  infrahub-sync whoami

3. Or run the CLI in the cluster, from the Sync image. Replace <your API token> with a token of
   the bearer tokens in the credentials Secret:

  kubectl --namespace {{ .Release.Namespace }} run infrahub-sync-cli --rm -it --restart=Never \
    --image={{ include "infrahub-sync.image" . }} \
    {{- with .Values.imagePullSecrets }}
    --overrides='{"apiVersion": "v1", "spec": {"imagePullSecrets": {{ toJson . }}}}' \
    {{- end }}
    --env=INFRAHUB_SYNC_API_URL=http://{{ $api }}:{{ .Values.api.service.port }} \
    --env=INFRAHUB_SYNC_API_TOKEN='<your API token>' \
    --command -- infrahub-sync whoami
