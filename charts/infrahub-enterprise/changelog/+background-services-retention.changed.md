The `small`, `medium`, `medium-data`, `large` and `large-data` config presets now start the separate background services pod with `infrahub tasks background-services` instead of `prefect server services start`. `prefect server services start` does not read the task manager retention settings, so it does not delete old task runs and keeps events for Prefect's default retention. The new command needs an Infrahub 1.13 or later image: with an older image, the background services pod fails to start.
