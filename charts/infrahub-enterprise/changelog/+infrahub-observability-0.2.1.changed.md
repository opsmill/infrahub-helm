The `infrahub` 4.34.0 dependency now includes the `infrahub-observability` subchart 0.2.1. The prefect-exporter readiness probe can now be set with `infrahub.infrahub-observability.prefectExporter.readinessProbe`, and its default timeout is 10 seconds instead of 1 second, so the prefect-exporter pod becomes Ready on instances where `/metrics` takes more than 1 second to respond. Extra environment variables for the prefect-exporter container can be set with `infrahub.infrahub-observability.prefectExporter.extraEnv`.
