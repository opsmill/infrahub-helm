Added the task manager retention settings to `infrahub.prefect-server.global.prefect.env`: `INFRAHUB_TASK_MANAGER_RETENTION_TASK_HISTORY` (`30d`), `INFRAHUB_TASK_MANAGER_RETENTION_ACTIVITY_LOG` (`30d`) and `INFRAHUB_TASK_MANAGER_RETENTION_PREFECT_OWN_EVENTS` (`2d`). The infrahub chart sets `7d` for the activity log. Infrahub reads these settings from 1.13 on. To change one value, set the whole list, because Helm replaces lists.
