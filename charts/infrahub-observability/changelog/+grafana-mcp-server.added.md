Add the Grafana MCP server, which lets an AI assistant such as Claude Code read the metrics, logs and traces of the stack through Grafana. It is off by default (`grafanaMcp.enabled`), needs a token for the assistant (`grafanaMcp.serverToken`), only reads, and sends no usage statistics. A hook Job creates a Grafana service account with the Viewer role and stores its token in a Secret. A `LoadBalancer` or `NodePort` Service needs a TLS Secret (`grafanaMcp.tls.existingSecret`).
