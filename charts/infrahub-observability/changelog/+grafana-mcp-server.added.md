Add the Grafana MCP server, which lets an AI assistant such as Claude Code read the metrics, logs and traces of the stack through Grafana. It is the `grafana-mcp` chart of the Grafana community (version 0.37.0), installed as a dependency, and it is off by default (`grafanaMcp.enabled`). It needs a token for the assistant (`grafana-mcp.serverAuth`), only reads, and sends no usage statistics. A hook Job creates a Grafana service account with the Viewer role and stores its token in a Secret. The chart refuses to render when a read-only option is removed, and when a `LoadBalancer` or `NodePort` Service does not serve HTTPS.
