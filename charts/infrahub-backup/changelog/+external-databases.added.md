Added `externalDatabase` values for a Neo4j or PostgreSQL database that runs outside the Infrahub namespace: `allowRestore`, `insecureTLS`, `timeout`, `scratchSize`, `neo4jAddress`, `neo4jBackupPort` and `postgresAddress`. Each one sets the matching infrahub-backup environment variable. `scratchVolume` adds a volume for the temporary files of the backup, such as an ephemeral PersistentVolumeClaim, mounts it at `/scratch` and sets `TMPDIR` to that path. These values need an infrahub-backup image with external database support.
